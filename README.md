## أول تشغيل (النسخ التجريبية غير موقّعة بعد)
- **ماك:** افتح الملف واسحب وريني إلى Applications. أول مرة: كليك يمين على التطبيق ← Open ← Open.
- **ويندوز:** إذا طلعت «Windows protected your PC»: More info ← Run anyway.
- **لينكس:** `chmod +x Wareeni-linux-x86_64.AppImage` ثم شغّله. التحكم يحتاج جلسة X11.
- **أندرويد/هواوي:** افتح الملف واسمح بالتثبيت من هذا المصدر.

`SHA256SUMS.txt` in each release lets you check a download.
